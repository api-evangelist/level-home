# Level Home

> Level Home makes the "invisible" Level smart lock family — Level Lock, Level Lock Pro, Level Bolt and
> Level Keypad — which hide the motor, radios and battery inside a standard-looking deadbolt. The locks
> speak Bluetooth LE, Thread and Matter and work with Apple Home (including Apple Home Key), Google Home,
> Amazon Alexa and SmartThings. ASSA ABLOY acquired the Level Lock hardware business in September 2024;
> the remaining Level Home, Inc. entity renamed itself Ambient Property Technologies and sells smart
> access and building intelligence to multifamily operators.

**Level Home publishes no developer API.** There is no developer portal, no OpenAPI or Swagger document,
no AsyncAPI, no webhook catalog, no MCP server, no A2A agent card and no first-party SDK on any package
registry. Integration with Level locks happens over device protocols (Matter, Thread, Bluetooth LE, Apple
Home Key) through the Apple Home / Google Home / Alexa / SmartThings ecosystems, or through the
third-party broker Seam, whose Level integration is still inquire-only. This file was generated by API
Evangelist from what Level publishes publicly; it is not served by Level.

## Machine-readable surfaces (both undocumented by Level)

- [Level website content GraphQL endpoint](https://level.co/api/): Craft CMS GraphQL API behind the
  marketing site. Anonymous introspection is enabled and returns 419 types, but the public schema scope is
  limited to `ping` and `globalSet`/`globalSets` (one implementation, `bundleDiscounts_GlobalSet`).
- [Level mobile application backend](https://api.level.co/): the host the Level Home iOS and Android apps
  talk to. AWS API Gateway; `{"message": "..."}` JSON error envelope; `x-request-id` on every response. No
  spec, no docs, no developer signup.

## Discovery documents

- [Apple App Site Association](https://api.level.co/.well-known/apple-app-site-association): Apple team

  paths `/invite/*`, `/pass/*`, `/verify/*`, `/recover/*`, `/franklin/in-home/opt-in/*`.
- [Android asset links](https://api.level.co/.well-known/assetlinks.json): delegates `co.level.app` and
  `com.ambientproptech.mdu` — the consumer and multifamily apps share one backend host.
